# Archived experiments

The repository root contains the current research. This directory preserves earlier versions for traceability:

- [initial_and_followup/](initial_and_followup/README.md): original fixed-interval experiment and first follow-up, with their code, tests, results and PDFs.
- [third_stage/](third_stage/README.md): the previous nested third-stage layout, including exploratory drivers, original frozen protocols/results and the report before root-path updates.

Historical source code and numerical files are preserved. Relative links in archived Markdown may be repaired to point to the archived files, but recorded numerical protocols and source hashes are not rewritten. Historical command examples describe the layout at the time; use the current [root commands](../README.md) for reproduction.

Current root outputs were regenerated from the same processed data, using saved control fits and unchanged numerical fitting functions. [Layout verification](layout_migration.json) records the comparison with the original arrays, goals and function bodies. The layout change does not introduce a new research method.
