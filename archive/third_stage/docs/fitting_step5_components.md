# 看懂兩個分量與剩餘誤差

本步只讀取上一個實驗保存的最佳解，不重新最佳化、不插入 goal、不加入懲罰。

從研究目錄執行 `python3 -m motion_decomposition.step5_explain_real_components`，產生[解說圖](../results/step5_real_components/contributions_and_errors.png)及[數值摘要](../results/step5_real_components/summary.json)。

## 圖左邊：每個分量負責多少位移

前三列把原公式 `p_hat=p0+S1*d1+S2*d2` 拆開。灰線是原始位置減去起點；藍線為 `S1*d1`，橘線為 `S2*d2`，黑色虛線是兩者相加。這些是加在起點上的向量貢獻，不是兩隻手腕，也不是兩條獨立的絕對位置軌跡。

程式先用 `design_matrix` 求兩條進度，再用 `basis[:, :, None] * displacements[None, :, :]` 得到每個時間、每個分量的 XYZ 貢獻。最後檢查：起點加上兩個貢獻，是否和保存的重建位置一致，容許差為 1e-12 m。

第一分量在 19.23489–19.98951 秒進行：X 約增加 15.86 cm，Y 減少 27.79 cm，Z 減少 27.20 cm，主要負責那次明顯的位置轉換。

第二分量在 19.99864–21 秒進行：X 減少 5.26 cm，Y 增加 4.53 cm，Z 減少 0.33 cm，主要負責後段回移。這是數值解對這段資料的解釋，尚未證明是生理上的兩個動作單元。

左下進度條從 0 變到 1。進度達到 1 後，該分量的位移貢獻仍然保留，不會回到 0；只有速度回到 0。兩分量在本解相隔 0.00913 秒，沒有重疊。

本解第一個累積 goal 為 `[-0.10408, 0.16321, 0.89840]` m，終點為 `[-0.15664, 0.20851, 0.89507]` m。它們由擬合位移累加得到。一般重疊情況中，軌跡未必通過中間 goal；本解因沒有重疊，在兩分量之間會暫時停在第一個累積 goal。

## 圖右邊：哪裡還沒重建好

前三列的殘差定義為「重建減原始」，正值代表該座標重建得較大。右下是三個方向誤差向量的長度，因此沒有負值。

最大位置誤差發生在 19.38333 秒，約 5.518 cm；當時 XYZ 殘差分別約 `[-4.298, 1.021, -3.307]` cm。這不是三個數字直接相加，而是平方和再開根號。

這個最大誤差發生在第一分量進行期間，並非只在裁切端點。圖上 X、Y、Z 的轉換細節不同，但單一分量三個方向共用同一條進度函數，因此每個分量沿固定方向移動。對曲線與不同方向錯開的變化，少量分量可能不足；本次觀察還不能區分分量數不足、局部解或模型其他限制各占多少。

在第一分量開始前，重建保持在起點，漏掉一些原始小移動；那 149 個樣本的位置 RMSE 約 1.634 cm。第一分量期間 90 個樣本約 3.721 cm，第二分量期間 121 個樣本約 1.798 cm。兩分量之間僅 1 個樣本，不能從該區間的數字推論穩定表現。這些區域長度和樣本數不同，僅作誤差定位，不能當成方法間的公平比較。

## 為什麼先做這一步

誤差變小只能說明更接近觀測位置，不能直接說明分量有合理意義。先拆開看，可確認位移加總公式、了解被省略的動作，並避免把兩個分量稱為已確認的真實動作。

下一個實驗是在同一短段、同樣端點與位置目標下，增加幾個小的分量數設定，保留相同初猜家族和每組搜尋預算，觀察位置、速度、初猜差異及分量互相抵銷的情形。這是數量影響的比較，尚不是自動選定數量，也不應直接把最大誤差位置當成新 goal。
