# 真實短段：共同求解的有無懲罰比較

## 怎麼做、為什麼這樣比較

沿用 18–21 秒的 361 個原始手腕樣本，固定觀測起終點位置，分別預設 K=2、3、4。每個 K 使用相同規則產生十組初猜，且不同權重共用相同初始時間及端點受限線性位移初值。沒有用上一個權重的答案初始化下一個權重。

共同求解器是 `joint_fit.py`，公式與人造驗證見 [共同求解說明](fitting_step6_joint.md)。本步沒有修改其目標函數或求解方法。

保留三種對照：

1. 步驟 5 的原無懲罰方法：每試時間，以線性最小平方法求位移，稱為 variable projection。
2. 新共同求解器、lambda=0：目標仍只有位置誤差，用來區分換求解方法的影響。
3. 同一共同求解器、lambda=1e-6 或 1e-4：才是有懲罰的配對版本。

每次最大 `nfev=1000`；相同上限不是相同運算時間。十組初猜規則和種子 23 沿用前一步。最短持續時間 2/120 秒、長度尺度 L=0.3 m、權重 0、1e-6、1e-4 都事前沿用人造實驗設定，僅作敏感度比較，不是已為這段資料校準，也沒有用結果挑一個最佳權重。

每個 K 與權重內，從成功停止、有限且端點合格的結果選總代價最低者；位置、速度、最大位置誤差、位移大小、停止原因及所有未合格結果全部保存。不能直接跨權重比較總代價大小，也不能因未合格解位置誤差更小而把它偷偷當成選中解。

## 如何執行

先依研究 README 產生短段和步驟 5 數量比較，再從研究目錄執行：

```bash
OPENBLAS_NUM_THREADS=1 python3 -m motion_decomposition.step6_joint_real
```

需要只重畫保存結果的 K=4 診斷時：

```bash
python3 -m motion_decomposition.step6_joint_real --diagnostics-only
```

執行會覆寫本步獨立結果目錄 `results/step6_joint_real/`，不覆寫舊實驗。90 次共同求解，每次完成即更新 `runs.csv`；完整摘要與陣列在全部求解完成後保存。

## 發現一：反向貢獻、誤差與權重有取捨

K=3 的權重增加時，位移長度與反向懲罰代價下降，但位置和速度誤差上升。K=2 選中解原本幾乎沒有同時反向貢獻，三種權重的結果在浮點差異以外相同。

K=4、lambda=1e-6 的位置 RMSE 為 1.12695 cm，最大位置誤差 1.93356 cm，位移長度加總 1.21778 m。相較先前原方法的 1.11077 cm 與 3778.38890 m，位置精度接近，選中解也沒有數千公尺的內部分量。這是不同目標和求解方法下的結果比較，不是從先前大抵銷解暖啟動後修復它的證據。

K=4、lambda=1e-4 的位移長度降到 0.54541 m，位置 RMSE 增至 1.35683 cm、速度 RMSE 增至 0.13505 m/s；較強懲罰不是所有指標都較好。

成分路徑長度超額比例在 K=4 小權重解仍約 52.39%，因此不能說所有反向貢獻都消失；該比例也包含非平行運動的疊加，不等於不必要抵銷百分比。位移長度加總更不是肌肉能量、實際腕部走過的總距離或生理合理性分數。

## 發現二：求解器和停止條件不能忽略

共同求解 lambda=0 時，K=2 有 6/10、K=4 有 9/10 達到 `max_nfev=1000` 而未成功停止。共 15 個未合格結果全部保留，不會放入成功解的選擇，但可以查看其最後迭代的位置、時間與位移。

K=4 的九個未成功停止解，位置誤差接近 1.1108 cm，位移長度加總已達約千公尺。只有一個成功停止解，位置 RMSE 1.3566 cm、位移 0.5486 m。這解釋為何新求解器的零權重選中結果，和原方法的零懲罰最佳解不同。

小權重 K=4 解的位置誤差比零權重選中解低，不代表加入懲罰在數學上能降低原位置目標的全域最小值。這些是不同局部搜尋與停止狀態下的有限次數結果。事實上，小權重選中解的反向代價比零權重那個小位移局部解還大；不能只憑權重正值就宣稱選中解必然比所有零權重解抵銷更少。

正權重的 60 組皆依規則成功停止，但不能從單一短段推論普遍提高成功率。也不能將更多次搜尋預算留給某個方法後，仍稱為完全相同預算。

## 驗證與目前結論

逐組檢查固定端點、時間範圍、最短持續時間、重建公式，以及總代價不高於自身初值。另從保存的 90 組陣列獨立重算位置、速度、最大位置誤差和反向懲罰，重現九個條件的選解，確認來源資料與舊基準摘要雜湊不變。37 項研究測試通過，圖表也已檢視。

目前支持的結論是：在這一個短段與這些預設條件下，有懲罰求解可得到沒有極大抵銷、位置仍接近觀測的解，但代價是擬合偏差與參數假設，且求解器、權重與初猜都影響結果。

尚未有真實分量標註、權重或數量自動選擇、全片段驗證或人體力學驗證。裁切端點原始速度不為零、模型解析端點速度為零的限制仍在。

下一步應先對照選中分量的位置、時間和速度，確認它如何完成重建；再討論尺度、權重敏感度與其他片段驗證。不能直接把這個結果稱為教授問題已完整解決，也不應立刻擴大數量掃描或決定最終 K。
