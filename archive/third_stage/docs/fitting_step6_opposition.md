# 反向貢獻懲罰：先用小例子驗證

## 目的與來源

步驟 5 的 K=4 解出現極大、幾乎同時且相反的位移。本步先測試一個明確的限制，觀察它如何改變解，而不是直接套用真實資料。

Liao 與 Kirsch (2014) 的 Methods C 在速度擬合代價中處理同時反向的成分。本步借用「需考慮同時反向貢獻」這個動機，但採用下述自行定義的向量內積懲罰，**不是重現該文公式或完整演算法**。參考來源：https://pmc.ncbi.nlm.nih.gov/articles/PMC4110007/ 。本步不主張懲罰具有已驗證的生理或力學意義。

## 先理解要處罰什麼

每個分量仍為 `S_i(t)*d_i`，速度為 `v_i(t)=S_i'(t)*d_i`。看同一時間的兩個速度向量：

- 內積為正：方向夾角小於 90 度。
- 內積為零：至少一個速度為零，或方向垂直。
- 內積為負：夾角大於 90 度，有反向的貢獻。

定義 `q_ij(t)=max(0, -v_i(t) dot v_j(t))`。只有負內積會留下正值。先向前移動、完成後再往回走，兩分量不會同時非零，因此不會因方向相反而受罰。

這也不是只會罰「不必要」的反向動作：真正需要的重疊反向修正同樣可能受罰。方法的偏差必須測試，不可把所有反向貢獻稱為錯誤。

## 本次明確測試的公式

```text
J = (1/N) sum_n ||p_hat(t_n)-p(t_n)||^2
    + lambda/N * sum_n sum_i<j [ (T^2/L) * q_ij(t_n) ]^2
```

N 是樣本數，T 是整段經過時間，L 是事先指定的正長度尺度，lambda 是非負權重。內積的單位是 m²/s²，乘 T²/L 後為 m，再平方為 m²，和位置誤差項一致；lambda 因此沒有單位。

本次 L 固定為 0.3 m，是人造例子的指定尺度，尚未為真實動作制定選取規則。lambda 測試 `0、1e-6、1e-4、1e-2、1`，這是觀察取捨的掃描，不是已選出的最佳權重。處罰項是各配對加總而非平均，因此 K 改變時配對數也會影響代價，後續比較必須明示這項設定。

同一公式在所有時間和速度上使用相同取樣，沒有設定角度硬門檻、沒有禁止所有重疊，也沒有改 minimum jerk 進度函數。這是離散取樣的代價，沒有保證控制樣本之間的所有行為。

## 為什麼位移不再只用線性最小平方法

原本只求位置平方誤差，時間固定後對位移是線性最小平方。現在速度內積包含位移相乘，再經截斷和平方，因此是非線性問題。

本步先固定所有開始、結束時間，只改位移。仍用 `d_K=終點-起點-sum(d_1...d_(K-1))` 保證端點，用原線性解作初值，再以 `least_squares` 求含懲罰的位移。lambda=0 時直接回傳原線性解，保持基準一致。沒有加入時間最佳化，也沒有改動步驟 5 的基準求解器。

程式 `opposition.py` 的 `opposition_residuals` 計算懲罰殘差，`fit_opposition_fixed_times` 求固定時間的位移。返回的總代價與位置 RMSE 分開保存，不能用較低的含懲罰代價宣稱位置更準。

## 三個小例子與結果

所有例子有 409 個樣本、120 Hz，固定起終點與時間；沒有搜尋分量數。

1. **幾乎相同的時間，容易互相抵銷。** 原始資料用一個 0.3 m 分量產生，再加上預先指定、兩端為零、振幅 1 mm 的正弦擾動。用兩個開始和結束時間僅差 0.0001 秒的分量擬合。這是刻意設計的數值壓力測試，不是人體噪聲模型。無懲罰時位移長度加總為 17.6838 m，位置 RMSE 約 0.5835 mm；lambda=1e-6 後加總為 0.3020 m，位置 RMSE 約 0.7062 mm。大幅壓低位移，但犧牲部分擬合精度。
2. **答案本來就有重疊反向分量。** 以 +0.4 m 和 -0.1 m 的重疊分量產生資料，並用已知時間擬合。無懲罰可恢復答案至浮點精度；lambda=1e-4 時位置 RMSE 增至約 2.4456 mm，lambda=1 時約 9.1059 mm。證明懲罰會偏離已知正確答案，不能把它當成辨識真實分量的保證。
3. **依序前進再返回。** 同樣 +0.4 m、-0.1 m，但時間不重疊。所有測試權重都保持約零的位置誤差，位移長度加總 0.5 m；因為沒有同時反向速度，懲罰為零。

[比較圖](../results/step6_opposition_toy/toy_comparison.png) 左邊是位置，右邊是位移長度加總（對數刻度）。許多位置線幾乎重疊，需配合 [CSV 數字](../results/step6_opposition_toy/runs.csv) 看；線重疊不表示分量相同。[完整設定與位移](../results/step6_opposition_toy/summary.json) 也有保存。

## 怎麼檢查是否算對

新增四項測試：同時反向會罰但依序返回不罰；同方向與垂直不罰且旋轉座標不改變結果；零權重和原線性解一致、正權重保持端點且可呈現精度取捨；錯誤權重或尺度會被拒絕。連同既有測試共 33 項通過。小例子另檢查每次擬合端點誤差低於 1e-12 m。

從研究目錄執行：

```bash
OPENBLAS_NUM_THREADS=1 python3 -m motion_decomposition.step6_opposition_toy
python3 -m unittest discover -s tests -q
```
