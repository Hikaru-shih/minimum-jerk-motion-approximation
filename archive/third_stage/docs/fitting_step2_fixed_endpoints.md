# 第二步重新設計：固定起點與終點

狀態：固定端點求解器、人造小例子與一組真實資料比較已實作並驗證。原本不固定終點的真實資料實驗、輸出及結論已移除。

## 1. 要解的問題

已知原始軌跡、起點、終點，以及各條 minimum jerk 位移的啟動與完成時間。固定數量與時間，只擬合位移及中間 goals，要求重建的第一幀與最後一幀分別等於指定位置。

這裡指定的起終點是整段重建的起終點。每個內部動作單元的邊界尚未辨識，不能因此說每個單元的起終點都已知。

## 2. 兩條位移的例子

假設起點在 2，終點在 8，兩條位移必須滿足：

```text
d1 + d2 = 8 - 2 = 6
d2 = 6 - d1
```

重建式：

```text
p_hat(t) = 2 + s1(t) d1 + s2(t) d2
         = 2 + 6 s2(t) + [s1(t) - s2(t)] d1
```

時間已固定，因此 s1、s2 已知。只需求 d1，再由 d2 = 6 - d1 算出第二條位移。中間 goal 可調整，但最後的位置不能改變。

## 3. 一般 K 條位移

令 p0 是起點，p_end 是指定終點，Delta = p_end - p0。若第一幀所有進度為零、最後一幀所有進度為一：

```text
d1 + ... + dK = Delta
dK = Delta - (d1 + ... + d_(K-1))
```

將最後一條位移代回重建式：

```text
p_hat(t) = p0 + sK(t) Delta
           + sum_{i=1..K-1} [si(t) - sK(t)] di
```

因此可建立新的線性最小平方問題：

```text
A[:, i] = S[:, i] - S[:, K]       （數學索引從 1 開始）
Y = 原始位置 - p0 - S[:, K] Delta
求 A @ D_free ≈ Y
```

求出前 K-1 條位移後，再計算最後一條。這是消去等式約束，不是在擬合完之後覆寫最後一幀，也不是把終點誤差乘上一個很大的權重。

上述簡化需要檢查第一、最後一幀的進度條件。如果片段結束時仍有位移未完成，應使用一般條件 S(T) @ D = p_end - p0，不能直接套用所有位移總和的式子。

## 4. 驗證項目

- 用可手算的兩位移例子確認起終點精確吻合，且內部仍能調整。
- 用已知答案的重疊軌跡驗證位移恢復，以及 rank 與不可唯一辨識的情況。
- 用不完全符合模型的資料確認：即使中間無法完全擬合，起終點仍滿足等式。
- 處理 K=1：唯一位移就是終點減起點，沒有自由的位置參數。
- 比較真實資料時，兩邊的數量、時間、指定起終點與評估方式相同。
- 報告位置、速度、最大位置誤差及兩端誤差。位置平方誤差最小不保證速度指標更好。

精確約束在數值計算中仍會有浮點誤差，必須用明確的小容許值檢查，不能把它當成動作品質門檻。

第一步的基本求解器仍用於原本的教學驗證。新函式 `fit_fixed_endpoints` 使用上述消去法，檢查所有成分在第一幀進度為零、最後一幀進度為一。時間不符合這個範圍就拒絕，不默默套用錯誤的簡化條件。

## 5. 小例子的實際結果

令四個時間為 0、1、2、3 秒，位置的 X 分量為 2、5、7、8；第一條位移在 0–2 秒作用，第二條在 1–3 秒作用。

兩條位移的總和必須是 6。中間兩幀的重建為 `2 + 0.5 d1` 和 `5 + 0.5 d1`，因此求解的是：

```text
最小化 (0.5 d1 - 3)^2 + (0.5 d1 - 2)^2
答案：d1 = 5，d2 = 1
重建 X：2、4.5、7.5、8
```

中間兩點各差 0.5，但起點、終點誤差均為零。這不是事後修改兩端，而是求解公式本身的限制。

另一個已知答案的三維重疊例子成功找回原位移，位置 RMSE 約 `1.72e-16` m。共新增六項測試，涵蓋手算案例、三維恢復、K=1、固定端點仍可能不可辨識、指定端點與觀測值不同，以及不合法輸入；全專案 42 項測試通過。

## 6. 真實手腕資料的受控比較

沿用先前 matched-count 比較中的 `fixed_interval_102`，共 6,086 幀、102 條位移。啟動時間與完成時間直接讀取已保存的結果，不重選、不重新估計。它不是第一次實驗原封不動的 0.5 秒基準。

兩個版本都指定原始第一幀、最後一幀為起終點。這是片段的觀測端點，不是另外標註的抓取目標；固定它們是本次實驗要求。

| 項目 | 原取樣版本 | 固定端點擬合版本 |
|---|---|---|
| 原始位置、影格、評估區間 | 相同 | 相同 |
| 位移數量 | 102 | 102 |
| 每條位移的啟動／完成時間 | 保存的時間 | 相同 |
| 指定起點、終點 | 原始首尾位置 | 相同 |
| 位移分量 | 原始取樣位置之差 | 在總和約束下聯合擬合 |
| 最佳化目標 | 無額外擬合 | 全片位置平方誤差 |

程式依序執行：

1. 讀取原始軌跡與舊時間，建立進度矩陣。
2. 用原取樣位移重算舊軌跡，核對位置與舊指標一致。
3. 固定總位移等於終點減起點，擬合 101 個自由位移向量；最後一條由等式決定，但其作用已包含在共同求解中。
4. 檢查首尾誤差、總位移與最小平方數值條件。
5. 換成消去第一條位移再求解，檢查是否得到同一重建，避免把某一條誤認成任意補償項。
6. 計算完整片段的三項誤差，另畫完整與 17–23 秒比較圖。速度先在完整片段計算，並未加入最佳化目標。

### 結果

| 完整片段指標 | 原取樣 | 固定端點擬合 |
|---|---:|---:|
| 位置 RMSE（cm） | 3.816595 | 3.146362 |
| 速度 RMSE（m/s） | 0.284609 | 0.291630 |
| 最大位置誤差（cm） | 31.203948 | 21.114118 |
| 起點誤差（m） | 0 | 0 |
| 終點誤差（m） | 0 | 0 |

固定兩端後，位置 RMSE 與最大位置誤差降低，但速度 RMSE 增加。此結果支持放開中間 goal 位置可以改善這組時間下的位置目標，不支持「整個動作全面改善」或「位移具有人體動作意義」。

局部圖中，21–22 秒附近的短促速度峰值仍未充分重建。時間基底沒有改變，而且目標函數只看位置，因此此步沒有解決動作邊界或速度重建問題。

### 數值檢查與限制

- 原取樣重建及其三項指標與先前保存結果一致，容許差為 `1e-12`。
- 新結果起終點與總位移誤差均小於 `1e-12` m；本次計算輸出為零，沒有覆寫最後一幀。
- 減少後的進度矩陣有 101 欄，rank 為 101，固定條件下的最小平方解可唯一決定。
- 消去第一條與消去最後一條的重建，最大座標差約 `1.71e-14` m。
- 相對最小平方正交殘差約 `2.71e-14`。
- 減少後矩陣的條件數約 216.53；這個數值依消去參數的選擇而變，不能單獨當成穩定性驗證。
- 原取樣位移滿足相同端點約束，所以它是可行解；新位置平方誤差不高於原解是預期的最佳化性質，不代表分解的動作語意已獲驗證。
- 此模型沿用原本的靜止端點進度條件，沒有要求吻合量測的首尾速度；不能由位置端點吻合推論原動作首尾確實靜止。
- 未加入時間擬合、速度代價、成分抵銷懲罰、動作數量選擇或人體力學驗證。

全專案 42 項測試仍通過。上述真實資料另有程式內的數值檢查，不只是看圖判斷。
