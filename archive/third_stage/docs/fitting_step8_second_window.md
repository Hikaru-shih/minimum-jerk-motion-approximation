# 另一片段：不調參的相同設定比較

## 為什麼換這一段

先前只在 18–21 秒研究權重，本次事前選定 30–33 秒，包含已在速度候選檢視中看過的 31–33 秒動作區域，向前保留一秒，讓兩段同樣長 3 秒。因懲罰公式含觀測時長 T，同樣時長可避免同時改變這個尺度。

範圍與設定在擬合開始前寫入 `protocol.json`，沒有看結果再更換時間範圍。這仍是同一個 ACCAD/AMASS motion clip、同一個人的右手腕，不是新受試者、另一個 clip 或獨立泛化測試。資料之前已被視覺檢視，也不稱為完全未見的盲測資料。

## 怎麼做

原始索引 3600–3960（零起算、包含兩端），共 361 個樣本、120 Hz，保留全域 XYZ，不平滑、不重取樣、不改位置。XYZ 變化範圍約 8.17、34.02、23.12 cm。

固定 K=4、L=0.3 m、最短持續時間 2/120 秒、最大 nfev=1000。權重為先前相同八個：`0、1e-7、3e-7、1e-6、3e-6、1e-5、3e-5、1e-4`。每個權重同樣十組均勻/速度低點初猜，種子 23、四組擾動、擾動比例 0.2、初始重疊比例 0.25。速度低點從新片段計算，因此初猜時間位置隨資料改變；規則不改，不是複製第一段的絕對時間。

不同權重共用相同初始時間及線性位移初值，不用上一權重的解暖啟動。固定新片段觀測起終點；時間與自由位移仍用 `joint_fit.py` 共同求解。每個權重各自選總代價最低的合格解，沒有跨權重挑出最終贏家。所有 80 組保留。

位置、速度指標對兩條短段軌跡都採相同有限差分規則。另保存全片先微分再裁切的原始速度，只用於資料檢查，不混用進主要比較。新片段原始端點速度約 0.0471、0.0551 m/s，依然非零；固定位置模型的解析端點速度為零，原先邊界限制仍在。

零權重時，未乘 lambda 的反向代價約 42.7936 m²；lambda=1e-6 時約 2.6760 m²；lambda=1e-4 時約 0.04261 m²。這是公式中的診斷量，不是人體能量或不必要抵銷的實際公尺數。

## 哪些現象重現，哪些沒有

**重現的取捨：**這些已測條件下，懲罰增加時，選中解的位移長度與反向代價降低，但位置誤差增加。速度誤差不完全單調，高權重下也較大。因此不能把抑制反向貢獻等同於更精準重建。

**未重現第一段的求解困難：**新片段全部 80 組成功停止，零權重也沒有出現第一段約千公尺的內部分量。這表示目前證據不支持「只有加懲罰才會成功」或「零懲罰一定會爆出巨大分量」。

第一段的零權重選中解受九組未收斂結果影響，位置誤差反而高；新片段則是零權重位置誤差最低。兩段共同支持的說法是懲罰改變分量與擬合取捨，不是它在所有片段都提高準確度。

新片段在目前選中指標中沒有重現第一段從 1e-5 到 3e-5 那種明顯跳變；但本步尚未對齊比較新片段的全部分量參數，不能因此宣稱分解平滑、唯一或不存在解群。

兩段的運動幅度、曲率、局部波動和誤差分布不同，不應直接拿 0.575 cm 與 1.127 cm 判定哪段方法更優，或合併成跨資料集成功率。

## 如何確認計算正確

逐組驗證固定端點、時間範圍、最短持續時間、原公式重建一致，以及總代價不高於自身初值。另讀取保存的全部 80 組結果，獨立重算位置/速度/最大位置誤差、反向代價與總目標，重現八個選解，確認原始軌跡與第一段摘要雜湊不變。既有 43 項研究測試通過，新增的是實驗入口，沒有修改求解器。

從研究目錄執行（前置第一段結果依 README 產生）：

```bash
OPENBLAS_NUM_THREADS=1 python3 -m motion_decomposition.step8_second_window
python3 -m unittest discover -s tests -q
```
