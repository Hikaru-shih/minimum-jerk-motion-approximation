# 第四步補充：第二組為何曲線接近但參數不同

本步只讀取已保存的五次時間擬合結果，進行診斷。沒有改求解器、增加懲罰或重選資料。這裡有已知答案，因此可以判定第二組沒有恢復生成資料的參數；真實資料通常沒有這種答案可核對。

## 1. 第二組實際改了什麼

| 參數 | 已知答案 | 第二組結果 |
|---|---|---|
| 成分 1 作用時間（s） | 0.20–2.20 | 約 0.0624–3.3884 |
| 成分 2 作用時間（s） | 1.20–3.20 | 約 1.0807–3.2450 |
| 重疊時間（s） | 1.0000 | 約 2.1643 |
| 成分 1 的 X 位移（m） | 0.3000 | 約 0.6711 |
| 成分 2 的 X 位移（m） | -0.1200 | 約 -0.4911 |
| X 位移總和（m） | 0.1800 | 0.1800 |

第二組把第一條作用時間拉長，並將兩條 X 位移都放大，再用更多相反方向的作用抵銷。因為總位移受固定端點約束，最終位置仍正確，但不能因此認為內部分解正確。

## 2. 怎麼看成分速度圖

[成分速度比較圖](../results/step4_timing_diagnostic/component_velocities.png) 左邊是已知分解，右邊是第二組；三列是 XYZ。

- 藍線：第一個成分的速度貢獻。
- 橘線：第二個成分的速度貢獻。
- 黑色虛線：兩個成分相加的速度。

這裡直接對模型的 minimum jerk 多項式解析微分，不是對位置做數值微分。右上 X 速度圖最清楚：藍、橘兩條速度的幅度都較大、反向重疊較久，但黑色合成曲線仍與左圖相似。

已知分解也有反向速度作用。兩條位移方向的夾角約 104.68 度，第二組約 151.79 度。因此不能把反向成分一律當成錯誤；目前只是觀察到第二組有更大的相反作用。

## 3. 路程診斷，不是懲罰函數

將每個成分的速度大小積分，得到各成分路程；再將合成速度大小積分，得到實際合成路程。

| 量 | 已知分解 | 第二組 |
|---|---:|---:|
| 各成分路程總和（m） | 0.56673 | 1.23256 |
| 合成路程（m） | 0.50925 | 0.51392 |
| 相對路程差 `1 - 合成路程 / 成分路程總和` | 約 10.14% | 約 58.31% |

兩組合成路程接近，但內部成分路程差很多。1.23256 m 不是手真的移動的路程，而是第二組各成分路程分別計算後的總和。

這項差值也會因非平行、非反向的成分而增加，不能全部解釋成不必要抵銷。測試另外使用兩條垂直位移，確認即使沒有反向速度，仍可能有路程差。它目前只作描述，不用來接受、拒絕或最佳化結果。

## 4. 為何求解器會停在這裡

第二組因 `ftol` 條件停止：後續代價下降量很小。`success=True` 表示符合某個停止條件，不表示已恢復真正時間，也不表示所有停止條件都達標。

我們額外畫出一條診斷路徑：將第二組的啟動／完成時間，逐步線性移向已知時間；每一點都重新擬合固定端點的最佳位移。共檢查 201 組時間，所有點都滿足時間範圍與固定端點要求。

[誤差路徑圖](../results/step4_timing_diagnostic/path_to_known_times.png) 顯示：

- 起點，也就是第二組：位置 RMSE 約 0.36270 cm。
- 朝已知時間移動 0.5%：約 0.36420 cm，誤差先提高。
- 路徑進度約 43.5%：誤差最高，約 1.32927 cm。
- 到已知時間：誤差接近浮點精度。

這條路需要先變差才會變好，因此只靠局部下降不一定走得到另一側。這不是證明所有方向都存在障礙，也不是嚴格局部極小值的證明；只是具體展示一條存在誤差隆起的可行路徑。已知時間只用於診斷，沒有提供給原求解器。

## 5. 這一步能下什麼結論

- 不同時間與較大的成分可以得到接近的合成曲線。
- 小重建誤差和求解器成功訊息，不足以確認成分參數恢復。
- 目前無懲罰版本對初始時間敏感；五組中四組恢復、一組得到次佳結果。
- 不應直接禁止反向成分，因為已知答案也包含它們。
- 尚未驗證抵銷懲罰是否改善第二組，不能把這個診斷當成懲罰有效的證據。

後續進入真實資料基準時，應明確記錄初始值集合、各次結果與選解規則。只能根據真實可取得的指標選解，不能使用人造實驗的已知時間差作選擇依據。有無懲罰的比較還要使用相同的初始值集合與限制。
