# 真實短段：時間與位移擬合

## 這次回答什麼問題

在同一段真實資料、相同分量數與固定起終點下，讓開始與結束時間也參與擬合，是否比只調整位移更能重建原始位置？這是短段的無懲罰基準實驗，不是最後的方法驗證。

資料為 18–21 秒、361 個原始手腕樣本。不平滑、不重新取樣。先固定 K=2，因為它是可觀察兩個分量關係、又方便逐一檢查的最小案例，不代表已辨識出兩個真實動作單元。最短持續時間為 2/120 秒，是目前沿用的數值限制，不是人體動作的合理時間下限。

## 如何執行

從 `research/motion_decomposition/` 執行：

```bash
python3 -m motion_decomposition.step5_inspect_real_window
OPENBLAS_NUM_THREADS=1 python3 -m motion_decomposition.step5_fit_real_window
```

前者保存短段；後者讀取它並將新結果寫到獨立的 `results/step5_real_window_fit/`。第二行的環境變數限制數值函式庫執行緒數，便於重現本次執行條件，不改變擬合目標。

## 程式如何做，以及為什麼

主要入口是 `motion_decomposition/step5_fit_real_window.py`，重用已驗證的求解函式。

1. `make_initializations(...)` 產生十組時間初猜：均勻分布與速度低點各一組，再各加四組可重現的小擾動。隨機種子為 23，擾動比例 0.2，初始重疊比例 0.25。這些比例只決定從哪裡開始搜尋，最佳化後不必保留。多組初猜用來觀察局部最佳化對起始猜測的敏感性，不保證找到全域最優解。
2. 每一組先呼叫 `fit_fixed_endpoints(...)`：保留該組開始與結束時間，只用線性最小平方法求位移，作為配對的固定時間基準。
3. 同一組再呼叫 `fit_timing(...)`：最佳化器調整時間；每試一次時間，就重新呼叫固定端點的線性最小平方法求位移。如此時間和位移配合調整，而不是先抄原軌跡的中間位置再調時間。
4. 十組全部保存。固定時間組選位置 RMSE 最低者；時間擬合組依既有規則，從成功停止、有限且端點合格的結果選位置 RMSE 最低者。精確同分選較早的列。位置與速度均另存，選解不用速度或抵銷指標。
5. 檢查端點誤差、時間範圍、最短持續時間，以及每組的位置誤差是否沒有比它自己的起始基準更差。輸入檔案前後雜湊也需一致。

速度低點初猜的內部節點為 19.95 秒，是在預定搜尋區間內挑出的候選，不是動作邊界的標準答案。摘要中的候選 `frame=234` 是短段內的索引；原片段索引為 2160+234=2394。

## 兩個分量如何求位移

仍用原本公式：`p_hat(t) = p0 + S1(t)*d1 + S2(t)*d2`。`S` 是各分量隨時間從 0 變到 1 的 minimum jerk 進度；`d` 是待求 XYZ 位移，不是力。

固定起終點代表 `d1+d2 = p_final-p0 = delta`，因此可先消去 `d2`：

```text
p_hat(t) = p0 + S2(t)*delta + (S1(t)-S2(t))*d1
```

給定時間後，S1、S2 都已知，最小平方法用整段 361 個樣本一起求 d1，再由 `d2=delta-d1` 得到第二個位移。這讓終點從公式上就固定，不是最後再修改某個樣本。

中間 goal 是 `p0+d1`，最後 goal 是 `p0+d1+d2`。中間 goal 不需要等於任何原始取樣點；它也不一定是重建軌跡會在某個時間通過的點。此模型中的目標與位移分量應和觀測軌跡區分。

## 本次結果

以下基準是本次十組初猜中最好的「固定時間、已擬合位移」版本，不是先前直接抄 goal 位置的舊實驗。

| 指標 | 固定時間、擬合位移 | 時間與位移擬合 |
|---|---:|---:|
| 位置 RMSE | 9.0626 cm | 2.3803 cm |
| 速度 RMSE | 0.33334 m/s | 0.15413 m/s |
| 最大位置誤差 | 21.3762 cm | 5.5181 cm |
| 起點、終點位置誤差 | 0、0 | 0、0 |

兩邊最佳解這次均來自 `uniform_4`，但選解規則沒有要求必須同組。十組時間擬合皆成功停止且位置誤差均降低，最後位置 RMSE 約 2.38–3.30 cm，顯示不同初猜仍會得到不同解；成功停止不等於找到正確的人體分解。最佳解依 `ftol` 停止，並非所有停止條件均達成。

選出的分量如下，時間皆是原片段時間，位移單位為公尺：

| 分量 | 開始 | 結束 | dX | dY | dZ |
|---|---:|---:|---:|---:|---:|
| 1 | 19.23489 s | 19.98951 s | 0.15863 | -0.27785 | -0.27204 |
| 2 | 19.99864 s | 21.00000 s | -0.05255 | 0.04530 | -0.00332 |

它們相隔約 0.00913 秒，這個解沒有時間重疊。原公式可以表達重疊，但目前沒有強制重疊；不能為了符合預期而把這個間隔改掉。第二分量的結束落在允許時間上界，需注意裁切範圍的影響。

## 圖怎麼看，還缺什麼

[位置與速度比較](../results/step5_real_window_fit/position_velocity_comparison.png)：黑線為原始資料，藍線為最佳固定時間，橘線為最佳時間擬合。橘線能更接近主要位置轉換，但漏掉部分前段小移動、轉折與速度變化，最大位置誤差仍約 5.52 cm。降低誤差不代表完整重現動作。

主要速度比較對原始與重建的短段位置都用相同 `numpy.gradient(..., edge_order=2)`，以免把不同微分規則混為同一指標。這和上一個檢視步驟「先對全片微分再裁切」的端點數值不同。摘要另記錄模型解析速度與全片微分參考的 RMSE，約 0.15417 m/s，不拿它替換表中的主要指標。

[分量速度圖](../results/step5_real_window_fit/component_velocities.png) 顯示兩個解析分量與相加結果。這次選中解沒有重疊，取樣診斷中沒有同時反向貢獻；不能據此推論其他初猜、分量數、資料也沒有抵銷問題。本步沒有加入抵銷懲罰，也沒有用此診斷選解。

原始裁切端點速度約 0.03169、0.07311 m/s；模型解析端點速度為零。固定位置沒有消除速度邊界不匹配。此外，只用兩個直線位移分量，尚未驗證能否表示這段曲線的細節。

本次不選最終分量數、不驗證全片段、不宣稱生理動作單元，也沒有重新訓練模型。下一步應先檢查這些時間與分量對圖上的誤差有何影響，再在相同資料與初猜規則下擴充分量數比較。無懲罰基準的設定確認後，才進行有懲罰的配對實驗。
